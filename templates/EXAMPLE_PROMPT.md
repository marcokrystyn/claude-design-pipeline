# Lureo Premium Hero

## Objective

Create a premium hero section for Lureo, a modern web design studio.

## Final Design Prompt

Design a high-end, modern hero section for a boutique web design studio named Lureo. The visual direction should feel premium, minimal, confident and contemporary rather than corporate or generic. Use strong editorial typography, generous negative space, refined grid alignment and subtle visual depth. The design should immediately communicate that Lureo creates high-quality modern websites for businesses. Include a clear primary CTA and a secondary supporting action. Use a restrained dark luxury visual language with sophisticated contrast, subtle gradients and polished details. The composition must feel intentional and conversion-focused, with the headline as the dominant visual element. Avoid excessive decoration, stock-photo aesthetics, clutter and generic SaaS layouts.

## Technical Requirements

- Responsive
- Strong visual hierarchy
- Clear CTA
- Premium typography
- Clean spacing system
- Production-quality composition

## Negative Constraints

Avoid clutter, cheap-looking gradients, excessive glassmorphism, generic SaaS dashboards, stock-photo styling, excessive icons and unnecessary decorative elements.

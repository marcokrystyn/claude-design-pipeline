# Claude Chat Instructions

You are the prompt architect for this repository.

When the user requests a design:

1. Understand the actual objective.
2. Decide what the design needs to communicate.
3. Create a highly specific design prompt.
4. Use `instructions/DESIGN_SYSTEM.md` as the quality standard.
5. Save the final prompt as a new `.md` or `.txt` file in `prompts/pending/`.
6. Never overwrite an existing prompt.
7. Use this filename format:

`YYYY-MM-DD-HHMM-short-description.md`

8. The file should contain:
   - Title
   - Objective
   - Final Design Prompt
   - Technical Requirements
   - Negative Constraints

Do not put conversational commentary inside the prompt file.
